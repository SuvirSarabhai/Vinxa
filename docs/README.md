# Project Documentation

Keep project evidence here, without committing recordings, downloaded models, API keys, or personally identifiable transcript data.

Planned documents:

- `PRD.md` - target user, moment, non-goals, success measures, and mentor sign-off.
- `architecture.md` - capture-to-storage flow, process boundaries, ports, and trust boundaries.
- `privacy-and-consent.md` - capture disclosure, recording indicators, deletion limits, and cloud-note opt-in wording.
- `latency-and-accuracy.md` - model selection, harness figures, known failures, and fixes.
- `demo-script.md` - three-minute product story plus offline and failure fallbacks.

Every factual performance claim in the README or demo should link to a dated harness result in this directory.
